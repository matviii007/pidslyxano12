# Підслухано у Ліцеї 8

Вебзастосунок для спільноти ліцею, де учні можуть ділитися дописами, спілкуватися та стежити за шкільними подіями.

## Можливості

- Реєстрація, вхід, профілі та аватари.
- Стрічка дописів із пошуком, темами та фільтрами.
- Анонімні дописи з модерацією.
- Відповіді, вподобання, репости та підписки.
- Сповіщення про взаємодії й рішення модерації.
- Звіти на дописи та ролі модераторів із налаштовуваними дозволами.
- Адаптивний інтерфейс зі світлою та темною темами.
- Майбутні події, якими адміністратор керує через Django admin.

## Технології

- Python 3.12
- Django 6.1.2
- SQLite для локальної розробки
- PostgreSQL для production
- Pillow, WhiteNoise і Gunicorn
