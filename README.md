# Підслухано у Ліцеї 8

Вебзастосунок для спільноти ліцею, де учні можуть ділитися дописами, спілкуватися та стежити за шкільними подіями.

## Можливості

- Реєстрація та двоетапний вхід за електронною поштою з одноразовим кодом, профілі й аватари.
- Стрічка дописів із пошуком, темами та сортуванням за датою або медіа.
- Анонімні дописи з модерацією; дописи верифікованих профілів публікуються автоматично.
- Опитування з одним голосом на користувача та допис.
- Вкладені відповіді, згадки через `@`, вподобання, репости й підписки без перезавантаження сторінки.
- Видалення власних дописів.
- Сповіщення про взаємодії, згадки й рішення модерації.
- Звіти на дописи та ролі модераторів із налаштовуваними дозволами.
- Telegram-адмінбот для черги модерації, скарг і статистики.
- Адаптивний інтерфейс зі світлою та темною темами.
- Майбутні події, якими адміністратор керує через Django admin.

## Технології

- Python 3.12
- Django 6.1.2
- SQLite для локальної розробки
- PostgreSQL для production
- Pillow, WhiteNoise і Gunicorn

## Електронна пошта

У локальному режимі (`DJANGO_DEBUG=True`) код підтвердження виводиться в консоль.
Для надсилання листів у production налаштуй змінні середовища `EMAIL_HOST`,
`EMAIL_PORT`, `EMAIL_HOST_USER`, `EMAIL_HOST_PASSWORD`, `EMAIL_USE_TLS` та
`DEFAULT_FROM_EMAIL`.

## Telegram-адмінбот

У файлі `.env` в каталозі `djangopidsluhano2` задай `TELEGRAM_BOT_TOKEN` та
`TELEGRAM_ADMIN_IDS` (Telegram ID адміністраторів, розділені комами). Не
публікуй цей файл і не передавай токен бота. Встанови залежності з
`djangopidsluhano2/requirements.txt`, виконай міграції та запусти бота окремим
процесом із каталогу `djangopidsluhano2`:

```powershell
python admin_bot.py
```

Бот дозволяє лише вказаним Telegram ID переглядати статистику, схвалювати,
відхиляти й закріплювати дописи, а також розглядати скарги.
